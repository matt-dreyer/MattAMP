# MattAMP tab voices

Short synthetic stock-voice clips generated for MattAMP on 2026-10-14 with
[edge-tts](https://github.com/rany2/edge-tts) and Microsoft Edge's speech service.
No celebrity recording, voice sample, or voice clone was used.

| File | Text | Stock voice | Rate | Pitch |
| --- | --- | --- | --- | --- |
| hell-yeah.mp3 | HELL YEAH! | en-US-EricNeural | -20% | -24Hz |
| send-it.mp3 | Send it! | en-US-MichelleNeural | -15% | -28Hz |
| meh.mp3 | Meh. | en-US-ChristopherNeural | -18% | -10Hz |
| yeah.mp3 | Yeah! | en-US-GuyNeural | -40% | -8Hz |

Leading/trailing silence was trimmed with FFmpeg. The radio clip was additionally
stretched with `atempo=0.72` (28% slower without changing pitch). All clips were normalized to -18 LUFS / -2 dBTP,
with a short fade-in and 80ms tail, then encoded as 24kHz mono 64kbps MP3.
The Game clip uses `atempo=0.88`, a 65Hz high-pass, +4dB at 150Hz, +2dB at
2.3kHz, 3:1 compression, gentle tanh saturation, and a quiet 65ms slapback before
the same loudness normalization. This gives it a heavier action-hero delivery
without raising its playback level.

The SkiCams clip uses `atempo=0.8`, a 65Hz high-pass, +3dB at 180Hz,
+1.5dB at 2.4kHz, and 3:1 compression before the same loudness normalization.
It is a slower, deeper female stock voice with more body and a firm delivery;
no named performer was used as a voice reference.

They are bundled media: no speech service or Python package is used at runtime.
Service-generated output is not covered by edge-tts's code license.

## Retro modem cue

`modem.wav` is an original 6.4-second synthesized dial-up homage, generated by
`scripts/synthesize-modem.py`: dial tone, DTMF digits, answer tone, warbles,
training-like noise, and a fading carrier. It is not a sampled modem recording
or a functional V.90 negotiation. 32 kHz mono PCM, softened boundaries, peak
limited to 0.7. No network connection or audio service is used.

It plays only when Retro is switched on, respecting the app volume, mute, and
Silly sound effects setting. Switching Retro off or hiding the app stops it.

## //e greeting

`apple2.wav` is an original acoustic-coupler-inspired tone sequence and robotic
“MattAMP ready. Let's get serial.” greeting. Generated by
`scripts/synthesize-apple2.py` using eSpeak NG's `en-us` voice. The synthesis
engine is not bundled. This is a playful homage, not an Echo II+ recording,
Bell 103 emulator, celebrity voice, or song sample. Plays once on choosing //e;
it respects Silly sound effects, volume, and mute. Restoring a saved skin does
not replay it.
