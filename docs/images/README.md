# Screenshots

Captured from MattAMP in October 2026 using a fresh, isolated profile. These are screenshots of the running app, not design mockups. No personal listen key, X session, or saved user data is included.

| Image | What it shows |
| --- | --- |
| `desktop.png` | Five-tab navigation, Synthwave artwork, wave background, and live workstation meters. Radio is stopped because this profile has no Premium key. |
| `skicams.png` | Heavenly's real Top of Tram player inside SkiCams, with 15-minute auto-cycle enabled. The provider controls the stream and its availability. |
| `skicams-settings.png` | The camera settings section with the four default views and favorite-management controls. |
| `artillery.png` | An expanded five-tank skirmish with an Unhinged arena and wraparound walls. |
| `victory.png` | The app's actual WebGL victory ceremony. A winning game state was staged in the isolated profile to capture it. |

The native camera pane is included through an Electron desktop capture of the isolated app window. The settings image is cropped to its camera section. The other images use the app window capture. Screenshots show the current source; the README marks game behavior added after the v0.2.0 release separately.
