# Approved DECK design

Preserve the approved DECK layout and interactions described below. The implementation in `src/` is the durable design reference.

Shell #232b34, titlebar #303b46, inset #111b23, edge #536271, foreground #e1e8ed, secondary #a8b9c7, accent #9ccab0, warning #dfb574. System font, 12–14px controls; monospace only for measurements. Compact native desktop controls. No bright panels or looping decoration.

Sidecar: media left, telemetry right. Stack: media above telemetry. DI.FM/Podcasts switch in the media panel. Full, compact and 56px bug states. Bug uses the audio-lines mark with a network dot, click to restore. Real YouTube embed retains native controls and visible viewport. Backend states drive play/error/availability labels.
